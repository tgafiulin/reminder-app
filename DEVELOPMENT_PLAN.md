# План развития Remindy

## 📊 Текущее состояние

**Основные реализованные фичи:**

- Базовый CRUD для напоминаний с контекстами/тегами
- Статусы (active/done) с визуальной индикацией
- Временные напоминания с браузерными уведомлениями
- Темная тема с переключателем
- Описание напоминаний (многострочное поле)
- PWA поддержка с офлайн-режимом
- Адаптивный дизайн для мобильных устройств

**Не реализовано:**

- `mediaUrl` (медиа-файлы) - есть в типах, но не используется в UI

---

## 🎨 Визуальные улучшения

### 1. Календарный вид

- Календарь с напоминаниями
  - Переключение: список ↔ календарь
  - Выделение дат с активными/просроченными напоминаниями
  - Клик по дате показывает напоминания
  - Месячный и недельный виды

### 2. Улучшенные карточки и анимации

- Плавные анимации появления/исчезновения
- Drag & drop для изменения порядка напоминаний
- Анимация при отметке "выполнено"
- Hover-меню с быстрыми действиями

### 3. Статистика и дашборд

- Виджет со статистикой в хедере или боковой панели:
  - Активные/выполненные/просроченные
  - Количество по контекстам
- Визуализация данных (графики, прогресс-бары)
- Статистика по периодам (сегодня, неделя, месяц)

### 4. Цветовая кодировка контекстов

- Цвета для контекстов (настраиваемые)
- Цветовые акценты в карточках
- Иконки для контекстов

### 5. Улучшенный хедер

- Поиск справа (если реализуем поиск)
- Меню настроек
- Статистика (активные/выполненные)
- Переключатель вида (список/календарь)

### 6. Боковая панель (опционально)

- Список контекстов с счетчиками
- Быстрая фильтрация
- Настройки

### 7. Пустое состояние

- Иллюстрации/иконки
- Подсказки для новых пользователей
- Быстрые шаблоны напоминаний

---

## ⚡ Функциональные улучшения

### Фаза 1: Базовые фичи (быстрые победы)

#### 1. Поиск и фильтры ⭐

- Поиск по тексту (заголовок, описание)
- Фильтры:
  - По статусу (активные/выполненные/все)
  - По контексту
  - По дате (сегодня/неделя/месяц/все)
- Сохраненные фильтры (опционально)
- Комбинация фильтров

#### 3. Сортировка

- По дате (по возрастанию/убыванию)
- По контексту (алфавитно)
- По статусу
- Пользовательский порядок (drag & drop)

#### 3. Повторяющиеся напоминания

- Шаблоны: ежедневно, еженедельно, ежемесячно
- Пользовательские интервалы
- Управление сериями (изменение всех/только будущих)
- Остановка/возобновление повторов

---

### Фаза 2: Расширенные возможности

#### 5. Медиа-файлы

- Поддержка поля `mediaUrl`
- Загрузка изображений (drag & drop или выбор файла)
- Ссылки на видео/аудио (YouTube, Vimeo и т.д.)
- Миниатюры для изображений
- Превью медиа в карточке

#### 6. Подзадачи

- Разбиение напоминания на шаги
- Чек-лист внутри напоминания
- Прогресс выполнения (%)
- Отдельные подзадачи как мини-напоминания

#### 7. Напоминания по времени (улучшение)

- Быстрые шаблоны: "Через 1 час", "Через 1 день", "Завтра"
- "Напомнить через X минут/часов/дней"
- Напоминания "каждый день в X часов"

#### 8. Архив

- Автоархив старых выполненных напоминаний (старше X дней)
- Ручное управление архивом
- Просмотр архива
- Статистика по архиву

#### 9. Календарный вид

- Интеграция с поиском и фильтрами
- Клик по дате создает новое напоминание
- Перетаскивание напоминаний между датами

---

### Фаза 3: Продвинутые функции

#### 10. Экспорт/Импорт

- Экспорт в JSON
- Экспорт в CSV
- Экспорт в ICS (iCalendar) для интеграции с календарями
- Импорт данных
- Резервное копирование

#### 11. Синхронизация (если нужен backend)

- Backend API
- Синхронизация между устройствами
- Облачное хранилище
- Офлайн-режим с синхронизацией

#### 12. Категории и метки (расширение контекстов)

- Несколько тегов у одного напоминания (вместо одного контекста)
- Иерархия контекстов (контекст → подконтекст)
- Цвета и иконки для контекстов

#### 13. Умные напоминания

- Анализ текста для автоопределения даты ("через 2 дня", "в пятницу")
- Автодополнение контекстов
- Рекомендации на основе истории

#### 14. Геолокация (опционально)

- Напоминания по местоположению
- "Напомнить, когда я буду рядом с..."
- Использование Geolocation API

---

## 🚀 Рекомендуемый порядок реализации

### Фаза 1 (быстрые победы)

1. **Поиск и базовые фильтры** - значительно улучшит UX ⭐ (текущий приоритет)
2. **Сортировка** - дополняет фильтры

### Фаза 2 (улучшение UX)

- **Календарный вид** - альтернативное представление данных
- **Статистика и дашборд** - визуализация прогресса
- **Улучшенная сортировка с drag & drop**

### Фаза 3 (расширение функциональности)

- **Медиа-файлы** - поддержка медиа-контента
- **Подзадачи** - разбиение сложных задач
- **Экспорт/Импорт** - работа с данными
- **Архив** - управление историей

### Фаза 4 (продвинутые функции - по необходимости)

- **Синхронизация** - если нужен backend
- **Несколько тегов** - расширение контекстов
- **Умные напоминания** - автоматизация
- **Геолокация** - если актуально

## 📝 Заметки

- **Приоритеты напоминаний** - решено не реализовывать в ближайшем будущем
- Все фичи должны работать в PWA режиме
- Сохранять обратную совместимость с существующими данными
